## Resource 2: Open Meteo

**What it provides** (1–2 sentences):
It provide free api about weather such as temperature, precipitation, humidity, wind speed, and forecasts for different locations.

**Docs link:**
https://open-meteo.com/

**Access:** API key needed? Rate limits? Cost? (write "none" if none)
No need api key if it is for personal use. It is free for 10000 api call per day. It will cost money if it is commercial use or you want to use over limits. 

**Sample response** (trim it to a few fields; paste the URL you called too):
